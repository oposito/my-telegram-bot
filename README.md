# 🤖 Telegram-бот для продажи цифровых лицензий

Оплата: **Telegram Stars**, **криптовалюта через xRocket** (все монеты) и **СБП по реквизитам** (проверка админом: автоматическая или ручная выдача). Опционально — карта/ЮMoney.
Выдача: уникальный ключ из списка (со своим сроком) + общий файл. Отзывы с модерацией, многоуровневая реферальная система, промокоды, рассылки, RU/EN.
Всё настраивается в боте: **🛠 Админ-панель** (или команда `/admin`).

---

## 1. Что подготовить

1. **Токен бота** — напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. **База данных PostgreSQL** (обязательно — на Infrlo файлы стираются при Redeploy):
   - встроенная база Infrlo, **или**
   - бесплатно на [neon.tech](https://neon.tech) / [supabase.com](https://supabase.com) → создайте проект → скопируйте *Connection string* (`postgresql://...`).
3. **Токен xRocket** — в [@xRocket](https://t.me/xrocket) → *Rocket Pay* → *Мои приложения* → создайте приложение → *API токен*.

## 2. Загрузка на GitHub

Распакуйте архив и загрузите **всё содержимое** в репозиторий `oposito/my-telegram-bot` (папка `app` должна лежать в корне репозитория, рядом с `requirements.txt`).
На GitHub: *Add file → Upload files* → перетащите файлы → *Commit changes*.

⚠️ Никогда не загружайте токены в GitHub — только в переменные окружения.

## 3. Настройка Infrlo

Команды уже правильные:
- Build: `pip install -r requirements.txt`
- Run: `python -m app.bot`

В **Settings → Environment Variables** добавьте:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `DATABASE_URL` | строка подключения PostgreSQL |
| `XROCKET_API_KEY` | токен Rocket Pay (можно ввести и в админке) |
| `ADMIN_IDS` | `1607904992` |
| `PUBLIC_URL` | `https://tgatfd.infrlo.com` |

`PORT` обычно задаёт сам хостинг. Если Infrlo просит указать порт — укажите `8080`.
Нажмите **Redeploy**, затем откройте **Logs**: должно быть `HTTP-сервер слушает порт ...` и `Start polling`.
Откройте `https://tgatfd.infrlo.com` — должно показать `OK`.

> Запускайте бота только в одном месте одновременно, иначе Telegram выдаст ошибку `Conflict`.

## 4. Первые шаги в боте

1. `/start` → выберите язык → **🛠 Админ-панель**.
2. **📦 Товары и ключи** → *Добавить товар* (`Название | Цена в ₽`) → заполните описание RU/EN.
3. *Добавить ключи* — текстом или .txt-файлом, по одному в строке:
   ```
   AAAA-BBBB-CCCC|30     ← ключ на 30 дней
   DDDD-EEEE-FFFF        ← бессрочный
   ```
   Если ключи кончились, а кто-то оплатил — заказ встанет в очередь и выдастся сам, когда вы добавите ключи.
   Для товара без ключей (только файл) выключите кнопку «🔑 Ключи».
4. **📁 Главный файл** → загрузите файл. При обновлении бот предложит разослать новую версию всем, кто уже купил. В «Мои покупки» покупатель всегда может скачать актуальную версию. У товара можно задать и свой отдельный файл.
5. **⚙️ Настройки** — тексты, курсы, наценки, способы оплаты, рефералы, каналы.

## 5. Способы оплаты

**⭐ Telegram Stars** — работает сразу. Цена в ⭐ = цена в ₽ / курс (`Настройки → Оплата → Курс ⭐`), либо ручная цена у товара. Возврат Stars: *Заказы → Найти заказ → Вернуть Stars*.

**💎 xRocket** — вставьте токен, и всё. Вебхуки **не нужны**: бот сам проверяет оплату каждые 20 секунд (и по кнопке «Проверить оплату»). Курсы монет берутся с биржи автоматически; можно задать вручную (`GRAM=1.5,NOT=0.002`) и ограничить список монет (`USDT,GRAM,BTC`).

**💳 Карта / ЮMoney (авто)**
1. Кошелёк ЮMoney → [Настройки HTTP-уведомлений](https://yoomoney.ru/transfer/myservices/http-notification).
2. Адрес: `https://tgatfd.infrlo.com/yoomoney`, скопируйте *секрет*, сохраните.
3. В боте: *Настройки → Оплата* → номер кошелька, секрет, включите «Оплата картой/ЮMoney».

**🏦 СБП по реквизитам (включено по умолчанию)**
1. *Настройки → Оплата → Реквизиты СБП (RU/EN)* — впишите номер телефона, банк и имя получателя.
2. Покупатель видит сумму и реквизиты → переводит → жмёт «Я оплатил» → присылает скриншот.
3. Вам приходит чек и три кнопки:
   - **✅ Подтвердить и выдать автоматически** — бот сам выдаст ключ из списка и файл;
   - **✍️ Выдать вручную** — вы отправляете любое сообщение (ключ, текст, файл, фото), бот перешлёт его покупателю и закроет заказ;
   - **❌ Отклонить** — покупатель получит уведомление.
   Все заказы на проверке также лежат в *🧾 Заказы*.

## 6. Оформление: кастом-эмодзи и премиум-стикеры

*🛠 Админ-панель → 🎨 Оформление*:
- **Кастом-эмодзи в текстах** — просто вставляйте премиум-эмодзи в приветствие, FAQ, описания товаров, реквизиты, рассылки — бот сохранит их.
- **📝 Тексты бота** — любой текст бота (RU/EN) можно переписать, в том числе с кастом-эмодзи. Переменные в `{скобках}` нужно оставить.
- **✨ Иконки кнопок** — пришлите кастом-эмодзи, и он станет иконкой кнопки (меню, «Купить», способы оплаты и т.д.). Иконку товара в каталоге задаёт кнопка *✨ Кастом-эмодзи товара* в карточке товара.
- **🖼 Стикеры** (обычные, анимированные, премиум) — при /start, после покупки, после одобрения отзыва и к ответу поддержки.

⚠️ Правило Telegram: боты могут показывать кастом-эмодзи, только если у **владельца бота** (аккаунт, который создал бота в @BotFather) есть **Telegram Premium**. Если Premium нет, бот не сломается — он автоматически покажет обычные эмодзи. Стикеры работают и без Premium.

## 7. Рефералы, отзывы, рассылки

- **Рефералы:** ссылка `t.me/вашбот?start=ref_ID`. Когда приглашённый покупает, пригласивший (и уровни выше) получает скидку: `Скидка по уровням` = `10,5,2` (1-й, 2-й, 3-й уровень). Есть максимум скидки, скидка новичку и режим «только первая покупка». Скидка тратится при следующей покупке.
- **Отзывы:** оставить могут только покупатели (1–5 ⭐ + текст) → модерация → публикация в боте и в канале (`Настройки → Отзывы`, бот должен быть админом канала). Можно дать скидку за отзыв. Удалить: `/delreview НОМЕР`.
- **Рассылка:** всем / RU / EN / покупателям / без покупок; любое сообщение + кнопки-ссылки, предпросмотр и отчёт.
- **Пользователи:** поиск по ID/@username, бан, изменение скидки, ответ, бесплатная выдача товара.
- **Поддержка:** сообщения пользователей приходят вам с кнопкой «Ответить».
- **Обязательная подписка** на канал — `Настройки → Основное`.
